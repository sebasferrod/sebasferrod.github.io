Introducción a Redes

Las redes son un conjunto de dispositivos interconectados que permiten la comunicación y el intercambio de datos entre ellos. Se utilizan en una amplia variedad de aplicaciones, desde redes domésticas hasta redes empresariales y globales.

En este documento, exploraremos los conceptos básicos de las redes, incluyendo su definición, tipos, topologías y protocolos.

Definición de Red

Una red de computadoras es un conjunto de computadoras autonomas (posiblemante cada una con un SO diferente) interconectadas (conexiones alambricas o inalambricas) para intercambiar informacion.

Ejemplo: Una red cliente-servidor

Una red con dos clientes y un servidor.
Los clientes quiza usan Windows y el servidor seguramente use una distribucion de GNU/Linux.

Ejemplo: Una red P2P

Una red con dos computadoras que se conectan directamente entre si, sin un servidor central, sin servidores fijos, todos son iguales.
Ambas computadoras pueden ser Windows, GNU/Linux o cualquier otro SO.
Ni la funcionalidad ni la informacion esta centralizada.

Ejemplo: Interconexion y topologia

Topologia es la forma geometrica que tiene la red (la interconexion).

Tipos de Redes

Las redes se pueden clasificar en diferentes tipos según su alcance, topología y tecnología utilizada.

  • Redes PAN (Personal Area Network): Dispositivos se conectan dentro del rango de una persona. Ejemplo Bluetooth.

  • Redes LAN (Local Area Network): Redes de área local, generalmente limitadas a un edificio o campus.

  • Redes MAN (Metropolitan Area Network): Estas redes abarcan la extencion de una ciudad o área metropolitana. Se pueden pensar como la interconexion de LANs.

  • Redes WAN (Wide Area Network): Redes de área amplia, que abarcan grandes distancias geográficas. Pueden cruzar oceanos.

  • Redes Interplanetarias (IPN): Se espera que InterPlaNetary (IPN) Internet sea el siguiente paso en el diseño y desarrollo de redes planetarias de espacio profundo.

Software de red

Para reducir la complejidad del diseño, la mayoria de las redes se organizan como una pila de capas.

Cada capa ofrece servicios a la capa superior mientras oculta los detalles de la implementacion.

Cuando dos capas (en diferentes hosts) se comunican entre si utilizan un protocolo (forma en que se lleva la comunicacion).

La capa le envía un mensaje a la capa 5 en otro host. Cada capa agrega un header que es información para la capa correspondiente en el host. Observar que los mensajes que se envían en la capa inferior tienen todos los headers de las capas involucradas.

Servicios vs protocolos

Los servicios son funcionalidades o la interfaz disponible en una capa a las capas superiores.

Un protocolo es el conjunto de reglas para comunicarse entre capas del mismo nivel.

Modelo OSI

El modelo OSI (Open Systems Interconnection) es un marco de referencia que define cómo se comunican los sistemas de red. Se compone de siete capas, cada una con funciones específicas.

Es una generalizacion del modelo TCP/IP y agrega dos capas nuevas y redefine la capa base en dos capas: Capa 1: Fisica y Capa 2: Enlace de datos.

  1. Aplicación: Proporciona servicios de red a las aplicaciones del usuario final.

  2. Presentación: Se encarga de la representación de datos, cifrado y compresión.

  3. Sesión: Establece, mantiene y termina sesiones entre aplicaciones.

  4. Transporte: Proporciona la transferencia de datos entre sistemas finales y garantiza la entrega confiable.

  5. Red: Se encarga del direccionamiento y enrutamiento de datos entre redes.

  6. Enlace de Datos: Proporciona la transferencia de datos entre dispositivos en la misma red local.

  7. Física: Define las características físicas de la red, como cables y señales eléctricas.
